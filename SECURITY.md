| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

The OrchX team takes security seriously. If you discover a potential security vulnerability (e.g. key leakage risks, vault isolation bypasses, or sandbox escapes), please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, report the issue via email or private security contact:
- Email: security@orchx.dev (or contact repository owners privately)

### What to include in your report:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any suggested mitigations or patches if available.

### Disclosure Timeline:
- We will acknowledge receipt of your report within 48 hours.
- We will provide a status update and estimated resolution timeline within 7 days.
- A public security advisory and fix release will be published once the patch is verified.
